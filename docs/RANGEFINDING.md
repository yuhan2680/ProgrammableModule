# 第九关：测距与蛇形隧道

## 世界与模块接口

`rangefinder` 是独立的 `0.5 × 0.5` 测距部件，通过已注册的 `RangefinderModule` 行为提供 `get_rangefinder_profile()`。JSON 仅引用受信任行为，不加载脚本。存活部件返回非空能力描述；失效部件与普通模块不提供测距能力。

`SimulationWorld.validate_distance_source(machine_id, module_id = "")` 只验证并返回实际来源。裸调用必须恰好有一个可用测距部件；多个来源应使用实例名，避免凭装配顺序选择。不存在、失效、错误能力的命名来源分别报错。

`query_distance(machine_id, angle_degrees, module_id = "") -> DataResult` 返回有限、非负的世界距离。方向与动作一致：0° 右、90° 上、180° 左、270° 下；接受任意有限角度并归一化，拒绝布尔值、非数字和无穷值。

起点是测距部件的**实际世界中心**，终点是射线上首个阻挡表面。未指定地块、未知地块、`collision: true` 地块及地图边界都阻挡；对象使用当前 tick 的真实状态，因此未落下的限时门、已解锁安全门和已毁对象不阻挡。其他机器的可用部件按实际矩形阻挡，整台自身机器均忽略。测量不读取贴图尺寸、像素、终点标记或 `radar_block`，也不追踪未来门状态。

地形射线使用有界 DDA，仅访问沿途跨越的格子，最多地图宽加高加四次；不扫描整片射线包围矩形。正交角度清理三角函数尾数，累加距离使用双精度。恰好接触阻挡角点或沿墙边行进也会读到表面，避免从墙角之间穿透。地图边界始终提供有限上限，因此没有命中对象时不会返回 `INF` 或人为固定量程。

测距是只读查询，不推进逻辑 tick、不发送模拟信号、不消耗冷却、不提交或取消动作，也不修改源地图。正在排队、运行或暂停的动作保持原状态。查询值是**传感器中心到表面的距离**，不等于整机安全行程；程序需要考虑模块尺寸和装配偏移，保留净空。

## 验证

`tests/rangefinder_world_runner.gd` 覆盖输入拒绝、裸/具名能力选择、损坏部件、实际偏移、四方向及任意角度、网格角点与切线、地形属性、地图边界、门与障碍实时状态、其他机器几何、原动作保留及长地图精度。小地图另用独立矩形遍历作几何基准。全部夹具只使用内存，不读取或写入玩家进度。

## 语言与权限

`ProgramParser.parse()` 第八个可选参数 `allow_distance` 默认为 false。开启后才解析 `distance(angle)`、`sensor.distance(angle)`、带括号的数值加减及六种比较（`< <= > >= == !=`）。具名查询仍需 `allow_named_calls`；`if / else` 仍需 `allow_conditionals` 且两条路径必须包含动作。比较不是赋值，暂不支持变量、逻辑组合、while 或自定义函数。裸 `distance()` 不能作为语句，避免纯查询构成无限循环。

AST 显式区分 `ExpressionNode`、`NumberNode`、`DistanceNode`、`BinaryNode` 与 `ComparisonNode`；保留数字节点的 value 兼容旧调用。深度与整树节点预算覆盖所有分支，并拒绝循环引用。运行前检查完整语法树、所有模块能力及常量值；不会用初始位置的读数预判后续动作。派发动作或进入条件时重新测量，动态负距离和非有限结果在对应源码位置终止。并行动作在同一世界快照中先求出所有参数，再一次提交，任一查询失败都不会提交部分动作。

`tests/rangefinder_language_runner.gd` 覆盖锁定权限、动态读取、算术与比较、有限回调、原子并行动作、错误位置、深度/节点上限与公开 AST 的循环引用。关卡本身通过现有 GameSession 运行，不另设捷径。
