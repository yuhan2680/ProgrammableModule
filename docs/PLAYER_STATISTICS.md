# 首次通关加权通过率

通过率为「成功权重之和 ÷（首次通关数＋首次通关前的失败次数）」。没有已结算尝试时显示 `—`。手动停止、离开关卡和地图编辑器测试不算失败。

同一关卡首次成功前，真实编译或运行失败继续计入分母。首次成功只增加一次成功及对应权重，之后的成功与失败都不再改变该关卡的通过率记录；重新打开应用后同样生效。教学、未来正式关卡与玩家关卡都参与，来源分类与关卡 ID 共同确定身份，改名或移动文件不能获得新的名额。

| 提示档位 | 权重 |
| --- | --- |
| 无 | 100% |
| 一般 | 50% |
| 多 | 30% |

首通前经历的最高提示档持久保存；中途关掉提示不能抹掉已经使用的辅助档位。

| 原始地图敌方整机数 | 权重 |
| --- | --- |
| 0 | 40% |
| 1—4 | 60% |
| 5—8 | 85% |
| 9 及以上 | 100% |

敌人数使用关卡完整的有效敌方机器清单，包含尚未出场的波次，排除关闭敌人功能时保留的配置和不参与模拟的未知行为条目；不按模块数或当前存活数计算。两个权重相乘：例如「多」加零敌人为12%；若此前失败一次，则该关首通后对总体分子贡献0.12，分母贡献2。

逐关记录作为玩家档案版本1的可选 `statistics.level_ledger` 保存。旧档案没有按关身份和提示档位，无法可靠反推首通记录，因此旧成功/失败总数保留，新通过率从更新后重新累计。UID、姓名、累计游戏时间、提示使用数、彩蛋记录和原耗时数据不受迁移影响。重复游玩的真实活动时间与提示使用仍照常累计；耗时记录沿用原有挑战计时规则。

删除玩家档案会清空逐关记录并生成新 UID；不会删除地图。模型使用有界字段校验和原子替换，保存失败保留原文件与有效内存。统计目录不与地图、通关进度或代码草稿共用文件。


## 教学关卡完成进度

统计页第一项「教学关卡完成进度」按当前版本教学目录中已通关的唯一关卡数 ÷ 当前教学关卡总数计算。教学来源与选关页一致，由 `res://data/levels/` 的实际有效关卡定义确定；完成事实复用 `GameDraftStore` 的通关标记，不受提示档位、失败次数或敌人权重影响。玩家地图、编辑器测试及已不在当前目录中的旧记录不参与。

每次打开统计页重新加载当前关卡目录，不保存固定的 16 关总数或历史百分比。例如已完成 16/16 时显示 `100%`；新版新增一关后显示 `94.1%`。数值最多显示一位小数，整数不显示 `.0`，未全通时最高显示 `99.9%`。全部完成才使用 700 字重及 `#ff2020`；增加未完成关卡或清除进度后恢复默认字重和颜色。没有教学关卡时显示普通 `0%`。

「清除预设进度」会清除该指标所用的教学通关标记；「删除玩家档案」沿用原边界，保留关卡进度，因此不会清空此项完成比例。计算只读取现有目录和记录，不新增存档字段，也不修改旧文件。


教学进度验证入口为 `tests/tutorial_completion_progress_runner.gd`：覆盖旧通关记录、目录增减、重复或过期 ID、损坏记录只读处理、未满百分比舍入、四种语言、红色粗体恢复以及编辑器试玩隔离；`player_profile_shell_layout_runner.gd` 同时检查新增首行在多种窗口、字体比例与语言下的排版。测试使用独占目录，不写真实玩家进度。


### 玩家关卡的提示权限

`properties.level.allow_code_hints` 缺省 false。禁用提示的关卡按无提示档参与本次权重记录，不因全局选择「一般 / 多」额外降权；允许提示的玩家关卡与教学关卡使用相同档位权重和最高已见档位规则。已有逐关最高档位和首通冻结记录保持不变。自动规划与验证不触发正式统计，实际插入提示才累计使用次数；禁止粘贴不阻止系统主动提供的提示。


## 首次运行日期与统计说明

「首次运行游戏时间」显示在最长关卡耗时之后、已解锁的未知统计之前，采用不补零的 `YYYY-M-D` 格式，例如 `2026-9-14`。档案顶层可选 `first_run_date` 以 `YYYY-MM-DD` 持久化本机当地日期：新用户首次启动时记录；旧版本未记录日期的档案，在升级后首次成功载入时原子补写当天日期，不根据文件修改时间猜测历史日期。后续启动、改名、统计更新和界面中的删除玩家档案都保留该日期。日期必须通过真实公历日期校验；写入失败或外部文件冲突时保留原文件与已有有效状态。

删除档案按钮下方右侧的「？」打开独立居中的白色圆角「关于统计」卡片。半透明灰色遮罩覆盖并拦截后景，标题和正文在窗口内部显示，正文与底部「关闭」按钮之间保留留白，不显示分隔线；Esc 或返回只关闭说明，恢复原页。正文说明统计依游戏行为自动计算关卡耗时及通过率，全部在本机进行、不上传云端。正文基准字号由 18 缩至约 60% 的 11，保留系统字号缩放；四种语言共用 384×384 逻辑像素的卡片，视口不足时缩小边界，语言切换不撑长外框。只有超出正文视区时才允许纵向滚动，并按上下剩余内容应用透明渐隐；到达首尾时对应边缘恢复清晰，标题和关闭按钮固定且不参与渐隐。
