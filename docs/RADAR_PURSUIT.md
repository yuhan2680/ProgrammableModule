# 第十关：猎人游戏

第十关按用户的新设定补齐为综合复习，不补做文档中未定的地图，也不要求常变量语法。地图为 `level_010`、order 10，选关位于九、十一关之间；原 `ProgramLevel.md` 保持历史原文。

## 关卡与学习目标

- 18×14 地图，内部 16×12 开放场地，未铺地和边界仍为 void。
- 玩家上限 3 个模块，允许 radar、movement、shooting。推荐雷达 (0,0)、枪 (0.5,0)、驱动 (0,0.5)。仍从空装配进入，代码只给空 main。
- 一个随机游走敌人，由一个真实移动模块组成，实例耐久 18。移速 0.75 格/秒，每 8–22 tick 抽取新方向与下一次转向时间；撞墙下一 tick 重新选择，持续游走而非固定巡逻。
- 120 秒内击毁目标完成。敌人不额外反击；难点为持续扫描、冷却判断、短距离追击与实际弹丸命中。雷达快照、枪口偏移、弹丸减速和命中算法全部复用现有规则。
- allow_variables、allow_radar 与 allow_random 开启，value（constant 别名）、variable、random() 和 randomInt(a,b) 均可选。不论是否使用绑定或随机函数，只要真实击毁目标即可通关。函数仍在十一关开放，旧关权限不变。

## 固定可信行为

`EnemyDefinition.RANDOM_WANDER` 注册 `random_wander`。配置需给出 `(0,1]` 的 speed_scale 和 1..600 的 turn_min_ticks/turn_max_ticks（下限不大于上限）；module_health 沿用有界的已有实例 ID 校验。可选 seed 仅为 0..2147483647 的整数。

RandomWanderController 自持 RandomNumberGenerator 和下一次转向的逻辑 tick。没有 seed 时每个世界随机初始化；正式地图不写 seed。固定种子支持导入地图重放和隔离测试，不使用共享随机源或帧时钟。每 tick 至多请求一次普通短移动，路程为实际可用驱动速度乘比例乘 tick 时长；扫掠、地形、障碍、动作取消及驱动损坏均由原世界处理。不会瞬移或绕过碰撞。

敌人 18 点耐久只写本次运行模块实例，不改变共享 movement 定义、玩家耐久或地图。暂停不推进随机源和模拟时钟；重置恢复耐久、生成新世界并保留代码与装配。

## 教学和提示

八页中英指引说明装配、判空、角度和距离、短步追击、弹道与冷却以及可选常变量和随机函数。工作台说明针对雷达追猎；状态药丸显示敌人剩余耐久、射击冷却和剩余时间，沿用全尺寸结果反馈。Tab 候选及指令集合按本关真实权限提供雷达、绑定和随机函数语法，近战、测距模块不在本关允许列表。

玩家可以直接用 `random()` 取 `[0,1]` 数值、用 `randomInt(a,b)` 取包含两端的整数，不需要额外模块。玩家随机源由自己的 Runner 持有，不与敌人的 random_wander 随机源共享；扫描、补全和界面刷新也不会改变采样序列。第十一关继承该能力，前九关保持关闭，详见 [随机函数](RANDOM_FUNCTIONS.md)。

代码提示使用无绑定、无随机函数的参考解法，保留用户可选常变量与随机函数，不强迫新语法。验证三条固定随机样本，且只对隔离副本设置种子；不会改变正式重试的随机性。见 CODE_HINTS.md。
