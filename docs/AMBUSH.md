# 第十三关：十面埋伏

依据 ProgramLevel.md 第十三关的两模块、雷达扫描及全方向敌人设定；此前已解锁雷达，本关直接继承，不回锁前关。用户指定中文名、十波、2.0 耐久及数秒残骸淡出。

- `level_013` / order 13，19×19 开放场地，180 秒，`destroy_waves`。
- 玩家从空装配开始；最多两个模块，推荐中心雷达 `(0,0)`、右侧射击 `(0.5,0)`。
- 十波依次出现，间隔 10 tick（1 秒），首波立即出现。前一整台机器确实毁坏才算清波；待生敌人不参与雷达、测距和弹丸碰撞。
- 每个敌人有一个移动和一个近战模块，各 2.0 耐久，不改全局模块定义或玩家血量。
- 方向连续随机覆盖 0～360°，每次重试重新采样，不能预先背诵八个固定角度。

## 随机布局和几何边界

`wave_approach_attack` 保留旧固定波次，新增可选 `random_spawn` 对象：有限 `center`、`radius`、`body_offset`。正式数据不含种子；仅测试/提示克隆允许注入合法 `seed`。每个世界独立随机源，不共享解释器的 random() 源。随机只在创建独立世界时采样，不在查询、暂停或绘制中采样。

`RandomWaveLayout` 只支持一个移动加一个近战模块。出生后先近战、后移动沿径向排列；接合处仅保留 0.00001 格浮点余量，避免共边被误判为重叠；两者使用原本 0.5×0.5 轴对齐矩形，不扩大弹丸、射线或命中框。`MachineFactory` 对随机后的每个实例执行原有地形、重叠校验；无效点直接拒绝，不能隐形挪到别处。

地图的机器参考点不要求是模块中心。此关明确把身体偏移设为 `(0.5,0)`，对应推荐装配的雷达到枪口间距；两块身体沿真实入射方向排列。这样从雷达读取参考点角度后，从右侧枪口发射的直线弹丸能实际穿过敌方模块。它是关卡布局设计，不是自动追踪或秘密弹道补偿。移动、查询、击毁全部采用实际模块，不改变 `scan().Angle()` 原义。不同玩家装配可能需要自行调整瞄准，教程与提示会说明建议布局。

## 程序与提示

```text
main() {
    variable aim = 0
    loop {
        variable target = radar.scan()
        if (target != null) {
            aim = target.Angle()
        }
        gun.shoot(aim)
    }
}
```

射击放在判断后，波次等待时继续执行动作推进逻辑 tick，避免只查询的无限空转。`data/hints/level_013.json` 绑定玩家真实模块名字；提示仅正式教学来源有效，并以固定种子的完整十波验证，不修改实际游玩随机性或世界。原三秒验证预算保留。

## 残骸淡出

`wreck_fade_seconds` 为分波行为可选正数，最多 30 秒，此关为 3.0。缺省 0 表示旧关卡保持残骸。只有整台敌人被击毁后才开始淡出；单模块损坏仍显示以提醒玩家还有残余目标。

MapCanvas 的独立显示时间同时淡化纹理、损毁标记、中心标记与最后一道攻击光束，结束后跳过整机绘制并停止无效帧刷新。暂停冻结，胜负结束继续完成淡出；更换/重置世界清空缓存。显示不删除模拟机器、不推进 tick、不更改波次与胜负，已毁敌人仍由原有规则排除在扫描/伤害目标之外。
