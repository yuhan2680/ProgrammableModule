# 编程工作台与覆盖预览

- 编程页左上角返回箭头回到同一会话的模块组装；返回前直接读取当前编辑器文本，包含尚未触发文本通知的最后一次输入。组装左药丸的右箭头与蓝色确认按钮共用装配校验并返回编程页。主光标、选区、滚动与字号在此次会话往返时保留；主动离开关卡才清理。
- 代码卡片移除内嵌装配标签和框外常驻说明。原来的简短执行规则追加为关卡引导的最后一个系统页，仅修改展示快照，不写入玩家地图。系统页可本土化，用户引导保持原文。
- 代码卡片左上角的减号、加号每次调整10个百分点，范围50%—200%，默认100%。控件复用原CodeEdit，不修改源码、撤销历史、选区或模拟状态；错误字号同步缩放。全局字体比例继续独立叠加。
- 代码框整体沿用浅色/深色偏好。提示及撤销提示放在独立工具栏，错误与运行消息放在框内底部；长消息在限定高度内滚动。位置坐标及模拟时间读数不再显示。代码输入区不绘制聚焦边框，仍使用原生键盘焦点、选区及闪烁光标。
- 基准代码卡片宽度为工作区的38%，至少430逻辑像素，始终右对齐；地图填满其余空间，两张卡片间隔16逻辑像素。
- 地图卡片右边缘可拖动至全尺寸，代码保持基准宽度与位置，地图在上层覆盖。地图实际进入代码区域后，相邻代码内容在约88逻辑像素范围渐淡，最低保留30%不透明度；独立同色圆角底板始终保持不透明，避免深色卡片透出浅色页面形成亮带。拖动不通过压缩代码区域实现。部分展开可停留，未覆盖的代码仍可操作；地图覆盖部分拦截点击与滚轮。
- 全尺寸按钮继续可用。过渡或持续拖动期间阻止重复运行和导航；Esc、右键、失焦或窗口变化取消进行中的拖动并回到起始比例。退出页面会取消补间，不能留下迟到回调。

验证入口：`workbench_code_layout_runner.gd`、`workbench_navigation_guide_runner.gd`、`curtain_preview_runner.gd`，并复用全尺寸、指引、配色、布局与游戏冒烟回归。
