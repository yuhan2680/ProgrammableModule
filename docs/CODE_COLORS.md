# 代码区颜色与显示

设置的「显示」分组按 Tab 补全、装配图尺寸自由缩放、颜色与显示、代码提示排列。点击「颜色与显示」进入独立子页，左上角返回药丸回到设置，再次返回进入主菜单。浅色和深色缩略图均使用实际只读 CodeEdit 绘制，整张样例与下方名称可点击，选中的样例带细亮边及柔和阴影；缩略图不接受代码输入，也不连接玩家草稿。

默认使用现有浅色模式。深色代码区底色精确为 `#121314`，同时调整正文、行号、语法、光标、选区、当前行、错误行、运行行和 Tab 灰字。仅代码编辑区域改变配色，页面、地图和外围卡片沿用浅色界面。预览与实际编辑器使用同一个 `GameTheme.style_code()` 方法，保证样例与真实配色一致。

深色模式下，代码提示和相邻撤销按钮使用深灰半透明圆底、局部背景模糊与细亮边，灯泡和撤销图标使用白色线条 SVG。浅色恢复原按钮资源与配色；按钮尺寸、提示规则和撤销语义不变。玻璃只采样按钮附近区域，图标单独清晰绘制且背景不截获输入；全尺寸过渡期间暂停采样以兼容整张代码卡片的淡出合成，收回后恢复。

偏好独立写入 `user://settings.json` 的 `interface.code_color_mode`，只接受 `light` / `dark` 字符串。旧配置缺少此字段时使用 `light`，载入时不改写原文件；保存继续保留未知扩展字段并采用临时文件、回读校验与替换流程。保存失败保留本次选择并显示错误，原有效文件不被半写覆盖。中英文名称仅影响显示，不参与存储。

已有工作台通过共享设置通知即时更新本地颜色，不重建编辑器、不重写代码，也不移动光标、选区和滚动位置或清除撤销记录。错误与执行行保留原行号，只切换底色；运行、暂停、提示插入和提示撤销仍遵循原会话规则。提示按钮预留边距不缓存旧底色，切换后不会因为显示或隐藏按钮而恢复为另一种颜色。地图编辑器试玩复用工作台，因此同样使用此偏好，但不会写入正式关卡草稿。

地图编辑器的「元数据 JSON」也接收同一设置实例，打开时使用已保存的配色，设置变化时仅更新现有代码区样式。深色背景同样为 `#121314`，字符串、数字、布尔值与 null 使用 JSON 高亮；原文、光标、选区、滚动和文本撤销记录保持不变。地图编辑器弹窗复用引导窗口的单层圆角外框与对称关闭按钮，标题栏和外围内容维持浅色。

地图的打开和另存为优先调用操作系统原生文件对话框，使用文件系统访问模式与 JSON 扩展名/MIME 过滤器，可选择其他目录。不支持原生文件对话框的平台继续使用修正圆角后的内嵌窗口；地图校验、实际写盘、取消和覆盖保护仍沿用已有流程。

独立回归入口：`code_color_settings_runner.gd` 验证默认值、迁移、持久化与失败保护；`code_color_editor_runner.gd` 验证配色、补全、编辑状态和真实运行状态；`code_color_ui_runner.gd` 验证页面点击、返回、重入和不同语言及窗口尺寸下的布局。它们只使用独占的 `user://tests` 子目录，最终结果记录于 [验证记录](VALIDATION.md)。

设置主页面及颜色子页移除外层白色卡片，各分组直接显示在浅色背景；分组灰底统一为 `#E5E7EB`，与页面的 `#F3F5F9` 保持清楚层次，组内分隔线使用 `#D0D5DD`。内容滚动边界对齐返回药丸底边，用 48 像素透明度渐变自然消失；没有额外白色覆盖或模糊，导航和弹窗独立显示。键盘导航会把操作项滚入完整可见区域。

两页的纵向滚动条与灰色分组之间保留 24 像素间距。初次进入和闲置时滚动条透明，滚动后显示，停止约 0.8 秒后用 0.2 秒淡出；拖住原生滚动条期间保持显示，移出窗口或释放后也能恢复淡出。仅改变透明度，始终保留原生滚动占位和滚动操作，避免卡片宽度随提示显隐跳动；单纯鼠标悬停不会唤出滚动条。

## 开始菜单背景

代码颜色选项采用紧凑预览，下方增加开始菜单背景分组。默认使用内置图片，纯色模式恢复原有 `GameTheme.BACKGROUND`；自定义图片添加后即选中。缩略图仅用简化白色窗口示意背景与前景关系，不复制真实菜单控件。图片在最终显示尺寸应用透明圆角裁切，与选中及未选中描边共用 1 像素内缩和 8 像素圆角；模糊缓存完成后再裁切，避免边缘变粗或露出方角。全部图片背景共用约 64 逻辑像素的高斯模糊，前景保持清晰。

`interface.menu_background_mode` 保存 `default` / `solid` / `custom`，`menu_background_id` 保存自定义项 ID，`custom_backgrounds` 保存 ID 和显示名称。缺少背景字段的旧配置保持默认图片，读取不会主动改写。图片解码后另存于设置文件同目录的 `backgrounds/<id>.png`，不依赖原始照片位置。选择、导入或删除保存失败会回滚本次背景变更，原设置继续有效；自定义文件丢失时使用内置背景。

默认、纯色模式、自定义添加入口和全部用户图片共享同一条横向列表；新增图片依序接在右侧，不另开第二排。横向可视宽度保持原来三个选项的宽度，整排溢出时显示原生滚动条，内置项也随整排移动；新导入的图片自动滚入可视区域。该横向条持续显示，不参与外层纵向滚动条的自动淡出。右键仅对未使用的自定义项提供紧凑删除菜单，宽高均不超过预览图的一半；默认、纯色和正在使用的图片不能删除。删除只影响游戏内副本，不删除用户原图。

背景设置与界面交互分别由 `menu_background_settings_runner.gd` 和 `menu_background_ui_runner.gd` 验证，使用隔离测试目录。
