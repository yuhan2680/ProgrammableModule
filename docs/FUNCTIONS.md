# 第十一关：函数复用

按用户要求暂时跳过第十关的地图。第十一关通过独立的 `allow_functions` 开放函数，同时通过 `allow_variables` 继承第十关文档中的 `constant` 常量、`variable` 变量与赋值；旧文档的 `value` 保留为 `constant` 别名。函数仍无参数、无返回值，前九关继续保持原权限。

```text
main() {
    dodge()
    dodge()
}

function dodge() {
    move(90, 1)
    move(270, 1)
}
```

顶层使用 `function 名称() { ... }` 声明，动作区使用 `名称()` 调用。支持声明位于调用前或后；名称区分大小写，必须是最长 128 字符的非保留英文标识符。`main`、`tick`、已有能力名称和控制关键字不能被用户函数覆盖。函数名称和模块实例名称是独立命名空间，具名动作仍通过 `模块名.动作(...)` 调用。

函数必须包含语句，且没有提前返回。执行进入函数体后逐句等待真实动作或并行组完成，函数结束自动回到调用点的下一句。调用与返回不消耗额外逻辑 tick。函数体可以使用当前关卡已解锁的动作、`if / else`、`loop`、`simultaneously` 和只读测距；每个能力继续独立检查权限。函数可调用其他用户函数；包含无限 `loop` 的函数会一直执行，后续语句不会提前运行。

`tick()` 与 `simultaneously {}` 的直接子语句不允许用户函数调用，避免将长动作、循环或条件放进有限回调或原子动作组中。`simultaneously` 本身可以出现在普通函数体中。空函数被拒绝；仅含计算语句的函数允许执行，但连续计算超过 4096 步会带行列报错，防止无动作循环阻塞运行。

函数可读取全局常变量，每次调用拥有新的局部作用域，不会读取或覆盖调用者的局部变量。声明、赋值与函数调用不消耗额外逻辑 tick；循环每轮重新创建自身局部存储。数值语法、初始化顺序、写保护和作用域规则见 [VARIABLES.md](VARIABLES.md)。

`ProgramParser.parse()` 的第九个参数是 `allow_functions: bool = false`，其后为独立的 `allow_variables: bool = false`。AST 的 `ProgramNode.functions` 保存独立声明，`UserCallNode` 保存目标名称与调用点行列，模块动作仍使用 `CallNode`。`ProgramFunctionValidation` 被 Parser 与 Runner 共用，完整建表后验证所有引用；所有函数（包括未使用函数）都参与检查。直接或间接递归均拒绝，最多 32 个函数、16 层函数调用；语句、动作、控制结构和表达式继续使用原有预算。调用图通过记忆化检查，不复制或指数展开函数体。

Runner 对所有函数体进行整树能力预检，未调用函数中的无效模块同样会在任何动作派发前报错。运行采用有界 `ExecutionFrame` 栈，按真实动作行高亮与报错，沿用世界的命令等待、取消以及 GameSession 的暂停与恢复。源文件不会转换成 GDScript，也不会执行任意宿主代码。

`tests/functions_language_runner.gd` 使用真实内容注册表与内存地图验证解析、前向引用、权限隔离、递归与深度上限、重复调用、嵌套返回、分支/循环/并行、实时测距、错误定位、同步取消与公开 AST 防御。测试不读写玩家存档。
