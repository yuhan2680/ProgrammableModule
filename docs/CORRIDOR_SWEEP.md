# 第十四关：通道清剿

依据直接读取的 GitHub `ProgramLevel.md` 最新原文，版本 `20d54b627eddf2888268fb050fdf670a4bc75fef`（2026-09-17）：第十四关练习移动中主动扫描、隔铁栅栏射击；雷达事件属于第十五关，本次不实现。文档写两个模块，但用户明确确认本关采用移动、雷达、射击三个模块。

## 关卡与地图

- `level_014`，order 14，18×35，最多三个模块，240 秒，目标 `destroy_waves`。
- 四格宽的纵向主通道，左右各五条一格宽支道，鱼骨式分布。玩家从下方向上前进，支道入口均为不可穿越的铁栅栏。
- 十波敌人依次激活，每组支道先左后右。前一整台机器被毁，且玩家推进到下一组支道的触发区域后，下一波才可出现。未激活敌人不进入机器表，不可被提前扫描或击毁。
- 每台敌人包含真实的移动与近战模块，**每个模块各 2.7 耐久**。敌人沿支道接近栅栏，受阻后保持朝主通道近战；贴近栅栏可能受伤，保持通道中线较安全。
- 击毁一个模块不算清波，走到道路尽头也不算通关。必须用真实攻击清除所有十波。
- 整机残骸沿用约三秒淡出；暂停冻结，终局继续完成淡出，重试清空。

## 栅栏与墙

新增可编辑地块 `iron_bars` 和 `wall`，采用 SVG。地块的可选布尔 `attack_block` 控制近战和弹丸遮挡，未指定时继承 `collision`，兼容旧定义和代码构造的地块。

| 地块 | 移动碰撞 | 攻击遮挡 | 雷达遮挡 |
| --- | --- | --- | --- |
| 地板 | 否 | 否 | 否 |
| 铁栅栏 | 是 | 否 | 否 |
| 墙壁 | 是 | 是 | 是 |

移动和测距仍读取 `collision`，不因攻击穿透而放行机器。未指定、未知地块和越界继续阻挡攻击与移动。雷达沿用独立 `radar_block` 语义，不把 void 新增为雷达屏障。所有判定使用真实格子、模块矩形和弹道，不依赖贴图空隙。

雷达遮挡扫描限制在线段包围格与贴边格内，省去无关远处墙壁。沿格线或擦角时仍检查两侧候选格，查询语义和快照内容不变。

## 波次触发

`wave_approach_attack.properties.activation_region` 是可选的 `{position: {x,y}, size: {x,y}}`。它必须是地图内的有限正尺寸矩形，边界由地图加载器校验。波次控制器检查玩家参考点是否位于区域，同时遵守原有出生时间与前波完成条件。

本关区域沿主通道向前延伸，不会因为一次较大步长跨过单条触发线而永久漏波；但仍建议用短步及时重新扫描。没有此字段的旧关卡继续原有纯时间触发。UI 不负责出敌，暂停和重试由同一个固定 tick 世界处理。

## 装配与教学方案

正常入口仍为空装配。建议中心雷达 `radar`，右侧 `(0.5,0)` 射击 `gun`，左侧 `(-0.5,0)` 移动 `drive`。

```text
main() {
    loop {
        variable target = radar.scan()
        if (target != null) {
            gun.shoot(target.Angle())
        } else {
            drive.move(90, 0.1)
        }
    }
}
```

发现目标时停下持续射击，无目标时短步前进。每条分支都有实际动作推进时间。雷达方向取真实雷达中心，弹丸从真实枪口出发；敌人身体相对参考点向右偏移半格，与推荐的雷达/枪口间距对应，不改变扫描结果或秘密修正弹道。不同装配可能需要自行调整瞄准。

该程序仅用于教程、文档和可撤销的逐步代码提示，初始代码保持空 `main()`。提示用完整真实战斗验证，不代扣血、自动移动或提前清波；导入同名关卡仍禁用教学提示。此前模块与指令解锁继续继承。

药丸显示击毁进度和射击状态，省略下一波倒计时。主通道推进与主动扫描的目标、教程、提示和新增地块名称均提供英文。
